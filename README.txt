# La Belle — Catálogo de Moda Íntima

## Como usar
1. Abra `index.html` no navegador.
2. Edite os produtos, preços e imagens em `index.html`.
3. As imagens ficam na pasta `assets/`.
4. No arquivo `script.js`, troque `5521999999999` pelo WhatsApp real da loja.
5. Para publicar, envie todos os arquivos para sua hospedagem.

## Observação
As imagens `produto1.jpg` a `produto6.jpg` são imagens demonstrativas estilizadas. Substitua-as pelas fotos reais das calcinhas, mantendo os mesmos nomes, ou altere os caminhos no HTML.
